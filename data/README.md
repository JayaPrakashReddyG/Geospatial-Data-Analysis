# Data folder

All files here are **synthetic demonstration data** generated by `scripts/generate_sample_data.py`
(fixed random seed, so regenerating gives identical files). They contain **no real customers, stores,
competitors or administrative boundaries** and must not be used to draw real-world conclusions.

| File | Rows | Description |
|---|---|---|
| `sample_sales.csv` | 7,500 | Orders from 1,800 invented customers across 20 invented zones (calendar year 2025) |
| `sample_stores.csv` | 19 | 9 `own` stores and 10 `competitor` stores |
| `sample_regions.geojson` | 20 | A 5 x 4 grid of square "zones" (Z01-Z20) - not real administrative areas |

Four zones (Z03, Z08, Z14, Z19) were deliberately given high customer density and no own store, so the
opportunity engine has something to find. That is a property of the *demo*, not a market finding.

## Schemas

### Sales / customers (`sample_sales.csv`)
| Column | Required | Notes |
|---|---|---|
| `latitude`, `longitude` | yes | WGS84 decimal degrees (aliases: lat, lon, lng) |
| `sales` | yes | Order value, >= 0 (aliases: revenue, amount) |
| `customer_id` | no | If missing, each row is treated as its own customer (a warning is shown) |
| `order_id`, `date`, `region`, `category` | no | `date` enables the date filter/trend; `category` enables category charts |
| `demand` | no | Numeric demand measure (e.g. units). If absent, `sales` is used as a proxy and the app says so |

### Stores (`sample_stores.csv`)
| Column | Required | Notes |
|---|---|---|
| `store_id`, `latitude`, `longitude` | yes | `store_id` must be unique |
| `store_type` | no | `own` or `competitor`. If absent, all stores are treated as `own` (warning shown) |
| `store_name`, `region` | no | |

### Boundaries (GeoJSON / zipped Shapefile / GeoParquet)
Polygon or MultiPolygon features with an identifier column named `region` (or `region_id`, `name`, `zone`,
`district`, `id`) and a defined CRS. Without boundaries, the app builds an auto grid (clearly labelled as
analysis cells, not administrative areas).
